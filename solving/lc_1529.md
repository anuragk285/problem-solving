# Minimum suffix flips

```java
class Solution {
    public int minFlips(String target) {
        char rightValues = '0';
        int ans = 0;
        for(char c : target.toCharArray()){
            if(c != rightValues){
                rightValues = rightValues == '0' ? '1' : '0';
                ans++;
            }
        }
        return ans;
    }
}
```
